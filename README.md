# AI Usage and Productivity Analysis
End-to-end analysis of AI adoption and usage patterns, uncovering insights into productivity, performance, user behaviour and satisfaction using Python, SQL and Power BI.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- MySQL
- SQL
- Power BI

## Dataset
- Source: Kaggle
- Total Records: 300
- Original and cleaned CSV files included.

## Project Steps

1. **Data Collection:** Collected the dataset from Kaggle.
2. **Data Cleaning:** Cleaned and prepared data using Python and Pandas.
3. **SQL Analysis:** Solved 8 SQL queries to find useful insights.
4. **Data Visualization:** Created 3 interactive dashboards using Power BI.

## Business Questions
1. Which AI tools are most popular among users?
2. Which professions use AI tools the most?
3. Does increased AI usage lead to higher productivity?
4. Which professions and AI tools save the most time?
5. Which AI tools have the highest user satisfaction?
6. Do students and professionals prefer different AI tools?
7. Does higher AI spending provide better productivity benefits?
8. Which combinations of profession, AI tool and AI purpose give the best results?

## Project Files
- `AI_Usage_and_Impact_on_Students_and_Professionals.csv` – Original dataset
- `AI_Usage_Cleaned.csv` – Cleaned dataset
- `AI_Useage.ipynb` – Python analysis
- `Ai_usage_pbi.pbix` – Power BI dashboards
